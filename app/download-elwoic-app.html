Distribution Architecture

How ELWOIC Distributes the App

ELWOIC separates version metadata from the installation binary so release metadata stays lightweight on ELWOIC's domain while large APK files are served as GitHub Release assets.

1. APK File — GitHub Releases

The installation binary (ELWOIC.apk) is published as a release asset on ELWOIC's public GitHub Releases page rather than as a regular browser-uploaded repository file, supporting files larger than standard browser upload limits.

2. Update Manifest — ELWOIC Cloudflare Pages

Version details, release notes, checksums, and download metadata are published at https://elwoic.in/app/version.json on ELWOIC's official domain via Cloudflare Pages.

Security & Authenticity

Signing, Integrity Checks & Transparency

How ELWOIC protects release authenticity and file integrity across independent distribution.

Independent Distribution Notice: This application is independently distributed and signed by ELWOIC. It is not Google Play Protect certified or officially Google Play verified, and no software download can be claimed as completely risk-free. Please review the concrete security and verification steps below.

Official Release & HTTPS Transport

The download link points directly to ELWOIC's official GitHub Release asset over HTTPS, and manifest checks target ELWOIC's official elwoic.in domain.

Permanent Signing Key via GitHub Actions

The APK is built and signed using ELWOIC's permanent Android signing key stored in GitHub Actions Secrets, with temporary keystore files removed after build and signatures verified during release. Future updates use the same permanent signing key.

In-App Package & Signature Validation

The app's update system performs SHA-256 verification (when supplied in the manifest), APK ZIP/archive validation, package ID and version-code checks, signing-certificate fingerprint checks, host/redirect restrictions, HTTPS handling, and storage checks.

Standard Android Installation

Once validated, installation hands off to Android's standard package installer rather than bypassing system protections.

Technical Verification: Current SHA-256 Checksum Expand / Collapse

A SHA-256 checksum helps verify that the downloaded ELWOIC.apk file matches the published release bytes without corruption or alteration—however, a checksum by itself does not establish publisher trustworthiness on its own.

Installation Guide

How to Install ELWOIC on Android

Follow these steps to download and install ELWOIC.apk on your Android device.

  1. 1

    Tap Download for Android

    Select the Download for Android button in the download section above to start downloading ELWOIC.apk.

  2. 2

    Wait for Download Completion

    Allow the ~44 MB APK file to finish downloading completely before opening it.

  3. 3

    Open ELWOIC.apk

    Tap the completed download notification or open the downloaded ELWOIC.apk file from your browser downloads or Files app.

  4. 4

    Review Install Permission Prompt

    If Android asks for permission to install apps from that browser or file manager, review the prompt and allow it only if you intentionally downloaded the APK from the official ELWOIC page.

  5. 5

    Tap Install

    Confirm the installation prompt in Android's package installer and wait for the setup to finish.

  6. 6

    Open ELWOIC

    Once installed, tap Open or launch ELWOIC from your app drawer.

About Android Installation Warnings: Android commonly shows a warning when installing apps from outside the Google Play Store. This is a normal Android security prompt for independently distributed APKs—not proof that the file is malicious. You do not need to disable Android security protections globally across your device.
Future Updates

Staying Up to Date

Once installed, you do not need to repeatedly visit this download page to look for new versions.

Automatic Background Checks

ELWOIC includes a background update-checking mechanism scheduled via WorkManager (configured for a 24-hour interval) that checks elwoic.in/app/version.json and notifies you when a newer release is published.

Manual Update Check in the App

You can also check for updates anytime directly inside the app by tapping the Check for Update button. When a newer version is available, the app can download and validate the new APK before installation.

FAQ

Frequently Asked Questions

Why is ELWOIC not available on Google Play Store?

ELWOIC is an independent, student-run, non-profit local weather observation and information initiative in Elamkulam, Malappuram, Kerala, and currently distributes its Android APK directly rather than through Google Play Store.

Is this an official ELWOIC application?

Yes. This download page is part of elwoic.in, the APK is published to ELWOIC's official GitHub Release, and builds are signed using ELWOIC's permanent Android signing key.

Why does Android show an installation warning?

Android displays a warning when installing an APK outside the Google Play Store. That prompt is standard Android behavior for independently distributed packages and does not by itself mean the file is malicious.

Where is the APK hosted?

The APK file (ELWOIC.apk) is hosted as a release asset on ELWOIC's public GitHub Releases page, while update metadata is served from https://elwoic.in/app/version.json on Cloudflare Pages.

How can I verify the downloaded file?

You can compute the SHA-256 checksum of your downloaded ELWOIC.apk file and compare it against the published SHA-256 value in the Security section above. The app also performs integrity and signing checks during update handling.

Will the application receive future updates?

Yes. When ELWOIC publishes a new release to GitHub Releases and updates elwoic.in/app/version.json, existing installations using the same permanent signing key can detect the update via the app's update-checking system.

Do I need to download the APK again for every update?

No. You do not need to repeatedly visit this web page to search for new releases—the app checks for updates automatically in the background (every 24 hours) and supports manual checking via its Check for Update button.

Is an internet connection required?

Yes. An internet connection is needed to download the APK, access live/online weather information and services, and check for updates.

What should I do if installation fails?

Confirm that ELWOIC.apk finished downloading completely, check that your device has enough free storage space, verify that installation permission was granted to the browser or file manager used to open the file, and try again.
